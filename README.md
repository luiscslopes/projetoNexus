# 🔐 NEXUS — Sistema de Identidade Digital

O NEXUS é um projeto web desenvolvido como forma de sair um pouco da teoria das aulas da faculdade e colocar em prática os conhecimentos que venho adquirindo em Análise e Desenvolvimento de Sistemas.

A ideia surgiu como um exercício pessoal para criar algo do zero, experimentar HTML, CSS e JavaScript e, principalmente, aprender através da prática.

## ⚙️ Funcionalidades

- 🔐 Login com validação de usuário e senha
- 🖥️ Dashboard após autenticação
- 🔑 Alteração de senha
- 🧭 Navegação entre diferentes páginas através do menu
- 👤 Página de identidade do usuário
- 🛡️ Página de segurança
- 🚪 Logout e retorno à tela de login
- 💾 Armazenamento da senha utilizando `localStorage`

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- LocalStorage

## 📚 O que estou praticando

Durante o desenvolvimento do NEXUS, estou praticando:

- 🧠 Estruturação de páginas utilizando HTML5
- 🎨 Estilização e organização de interfaces com CSS3
- ⚙️ Manipulação do DOM com JavaScript
- 🖱️ Criação de interações e eventos com JavaScript
- 🔐 Lógica de autenticação e validação de login
- 💾 Utilização do `localStorage` para armazenamento de dados no navegador
- 🧭 Navegação entre diferentes páginas
- 🗂️ Organização de arquivos e estrutura de um projeto web
- 🐙 Versionamento do projeto utilizando Git e GitHub

## 🚧 Status do projeto

Projeto desenvolvido para fins de estudo e aprendizado prático.

O NEXUS continua em desenvolvimento e novas funcionalidades podem ser adicionadas conforme avanço nos estudos.
